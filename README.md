# BEA'S KIOSK

Warm, responsive customer ordering UI starter for BEA'S KIOSK.

## Included in this starter
- Responsive menu with the provided menu items and descriptions
- Category filters and menu search
- Working in-browser cart and quantity controls
- Checkout form preview for pickup/delivery and payment method selection
- Main logo and secondary watermark assets supplied by the business owner
- Warm cream, caramel, and coffee-brown styling

## Important status
This is the **frontend starter**, not a live ordering system yet. Checkout intentionally does not submit or store orders. Supabase authentication, database tables, secure receipt storage, owner dashboard, realtime order tracking, and payment verification must be implemented before real customers can place orders. Currency symbol is provisional and must be confirmed before launch.

## Run locally
Install Node.js, then run:

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
